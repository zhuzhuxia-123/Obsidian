# Grounding DINO 名词与缩写解释

本文配合[组会汇报文档](Grounding_DINO_组会汇报.md)阅读，解释其中的专业名词、英文缩写、数据集名称和公式符号。定义以这篇论文的使用方式为主；为理解术语补充的例子均是教学示例，不是论文实验结果。

初次阅读时，先掌握这条主线：**图像与文本进入各自的骨干网络 → 特征增强器让两种信息交互 → 语言引导查询选择筛选候选位置 → 解码器细化候选 → 输出框与短语 → 用AP或定位准确率评价结果。**

## 一 先掌握的十二个词

| 名词 | 先用一句话理解 |
|---|---|
| 目标检测 | 在图中找到对象，并判断它是什么 |
| 开放词汇检测 | 用可变化的文字指定要检测的类别 |
| Grounding | 把文字中的对象对应到图像里的位置 |
| 特征 | 网络将图像或文字编码成的数值表示 |
| 骨干网络 | 将原始图像或文本转换成特征的基础网络 |
| 对象查询 | 一个会从特征中检索对象信息的候选表示 |
| 交叉注意力 | 一组表示从另一组表示中读取相关信息 |
| 预训练 | 先利用较大或较通用的数据学习基础能力 |
| 微调 | 在已有参数基础上继续训练，以适配任务或数据 |
| 零样本迁移 | 本文中，不用目标数据集的训练划分训练，就直接评测 |
| 消融实验 | 改掉或移除某个设计，观察结果如何变化 |
| AP | 综合检测结果排序、精确率和召回率的性能指标 |

## 二 任务与基本概念

### 1 目标检测 Object Detection

对一张图中的多个对象，同时给出**类别**与**位置**。例如找到两只狗和一个人，并分别画出矩形框。

与图像分类的区别是：分类主要回答“图中是什么”，检测还回答“有几个、分别在哪里”。

### 2 类别与实例 Category and Instance

**类别**是对象的种类，例如“狗”。**实例**是一个具体对象，例如图中左边那只狗。两只狗属于同一个类别，但对应两个实例。

理解这一区别，才能区分“找出所有狗”和“找出左边那只狗”。

### 3 边界框 Bounding Box 或 Box

用来描述对象位置的矩形，常以左上角和右下角坐标，或中心点、宽度、高度表示。

它描述的是一个矩形区域，不等于对象的精确轮廓。狗的检测框通常也包含周围少量背景。

### 4 闭集目标检测 Closed Set Object Detection

训练和预测围绕一个预先规定的类别集合进行，分类头通常输出这些固定类别的得分。

例如模型只设置“人、汽车、狗”三个类别时，不能仅靠输入一个新词，就自动增加一个训练充分的新类别分类器。

### 5 开放词汇检测 Open Vocabulary Object Detection

借助文本语义，让用户通过类别名称指定检测目标，减少对固定类别编号表的依赖。

“开放”描述的是类别输入方式和泛化目标，**不代表模型已经拥有所有类别的视觉知识**。模型可以接受某个专业病害名称，但未必识别得出相应图像。

### 6 开放集与开放世界 Open Set and Open World

在更广泛的研究中，这些术语可能还涉及未知类别拒识、未知对象发现或持续学习，具体定义因论文而异。

Grounding DINO在第2页脚注中将open-set、open-world、open-vocabulary detection作为本文的同一任务表述。讲解时应说明这一约定，不能因此推断它具备完善的未知类别发现与拒识能力。

### 7 视觉定位 Grounding 或 Phrase Grounding

让文字中的词或短语对应到图像区域。例如句子“A dog is beside a chair”中的“dog”和“chair”分别对应两个框。

在这篇论文中，grounded pre-training指利用区域与文本的对应关系预训练；不要把它理解成大语言模型语境中常说的“检索资料后再回答”。

### 8 指代表达理解 REC

全称为**Referring Expression Comprehension**。根据一条描述，在图像中找出它所指的对象。

例如“左边戴眼镜的人”不仅包含“人”这个类别，还包含位置和属性要求。本文评测时取最高分框作为输出，因此“找出所有人”不等于完成这一任务。

### 9 细粒度理解 Fine Grained Understanding

识别比大类别更细的区别，例如颜色、姿态、属性、细分类别，以及对象之间的关系。

“找人”偏类别识别；“找站在自行车旁边、穿红衣服的人”需要更细的语义判断。细粒度不只是“物体很小”。

### 10 多模态与跨模态 Multimodal and Cross Modal

**模态**是信息形式，例如图像和文本。**多模态**表示系统处理多种形式；**跨模态**强调这些形式之间的联系与交互。

这篇论文同时处理图像和文本，并让两者交换信息。仅仅把两个编码器放在同一系统里，并不自动意味着它们已经充分对齐。

### 11 图像分割与掩码 Segmentation and Mask

分割通常要判断哪些像素属于某个对象；掩码是表示这些像素位置的数组或图像。

检测框给出矩形，分割掩码给出更精细的形状。Grounding DINO本身输出框和短语；与其他模块组合获得掩码，不等于检测器原生执行分割。

### 12 图像生成与局部重绘 Generation and Inpainting

图像生成产生新图像；局部重绘根据指定区域及提示修改图像内容。

论文的编辑示例把Grounding DINO提供的位置交给外部生成模型。**定位提示**告诉检测器“找什么”，**生成提示**告诉生成模型“改成什么”，二者作用不同。

## 三 模型与网络名称

### 13 Grounding DINO

本文提出的语言条件目标检测器。其基本思路是把DINO检测架构与区域—文本定位预训练结合，并在特征增强、查询选择和解码三个阶段使用语言信息。

名称中的Grounding强调文字与图像区域的对应，不表示模型会生成长篇文字回答。参见[Grounding DINO原论文](https://arxiv.org/abs/2303.05499v5)。

### 14 DETR

通常写作**DEtection TRansformer**。它把目标检测看成集合预测：用一组对象查询输出一组框，再把预测与真实目标进行匹配。

理解“DETR类模型”时，先抓住“对象查询、集合预测、匹配训练”三个特点。集合预测不要求输出顺序和真实对象顺序一一预先对应。

### 15 DINO

本文中的DINO是**DETR with Improved deNoising anchOr boxes**，属于DETR类检测器。Grounding DINO在它的基础上加入语言相关模块。

需要特别区分：计算机视觉中还有同名的自监督表征学习方法，**本文的基础检测器DINO不是那个同名方法**。参见[DINO检测器原论文](https://arxiv.org/abs/2203.03605)。

### 16 GLIP

全称为**Grounded Language Image Pre-training**。它将目标检测和短语定位统一起来，学习具有语言语义的对象级视觉表示。

在本论文里，GLIP既是重要比较基线，也为部分图像描述数据提供伪框。Grounding DINO继承并发展了这条定位预训练路线。参见[GLIP原论文](https://arxiv.org/abs/2112.03857)。

### 17 GLIPv2与DetCLIPv2

它们是实验表中的其他视觉语言检测方法。GLIPv2是GLIP路线的后续工作；DetCLIPv2是另一种开放词汇检测预训练方法。

这里首先要辨认的是“比较对象”，不必在首次组会上讲完各自内部结构。DetCLIPv2使用的CC15M等数据与Grounding DINO的配方不同，所以性能差异不能直接等同于架构差异。

### 18 Transformer

以注意力机制为核心的信息处理架构，常结合前馈网络、残差连接等组件。它既能用于文本，也能用于图像和多模态任务。

在本文中，它使图像特征、文本特征和对象查询能够通过相似的交互模块交换信息。Transformer不是某一个具体数据集，也不天然等于能生成文本的大语言模型。背景见[Transformer原论文](https://arxiv.org/abs/1706.03762)。

### 19 Swin Transformer

一种用于视觉任务的分层Transformer，Swin名称来自**shifted windows，移动窗口**。它在局部窗口内计算注意力，并通过窗口移动建立跨窗口联系。

本文用它提取多尺度图像特征。Swin-T中的T表示Tiny，Swin-L中的L表示Large，是不同规模的骨干版本。参见[Swin原论文](https://arxiv.org/abs/2103.14030)。

### 20 BERT与BERT base

BERT全称为**Bidirectional Encoder Representations from Transformers**。它综合词元左右两侧的上下文，产生文本表示；base是其一种规模版本。

本文使用BERT-base编码输入文本。它在这里的作用是理解和表示文本，不是像聊天模型那样逐字生成答案。参见[BERT原论文](https://arxiv.org/abs/1810.04805)。

### 21 ResNet 50

一种具有残差连接的视觉网络，50表示其命名所对应的网络深度版本。它可以作为图像骨干。

论文的闭集补充实验使用ResNet-50；主要T/L模型使用Swin。比较结果前要检查骨干，不能把不同骨干的差异全归于新增语言模块。

### 22 T与L模型

在Grounding DINO的表格里，T和L主要区分使用Swin-T或Swin-L的模型变体。

但两种模型的训练数据版本、数据配方和训练资源也可能不同。它们并不构成“只改变网络大小，其余完全相同”的严格对照。

## 四 特征与注意力机制

### 23 特征与特征向量 Feature and Feature Vector

网络把输入转换成的一组数值表示，用于后续识别、比较或定位。特征向量是按维度排列的一串数。

可以把它理解为模型内部描述图像区域或词语的方式，但不要把其中每一维都直接解释为“颜色”“形状”等人工定义属性。

### 24 隐藏维度与特征维度 Hidden Dimension

表示每个特征向量有多少个数值分量。本文将公共特征维度设为256，使图像与文本特征能够进行后续匹配。

**256维不是256个类别，也不是256个目标。**它描述的是表示空间的宽度。

### 25 词元 Token

模型处理文本时使用的基本单位，可能是单词、子词、标点或特殊符号。

一个英文单词可能对应多个词元。因此“最多256个词元”不等于“最多256个英文单词”，更不能直接理解为256个类别。

### 26 图像位置与视觉词元 Image Token

图像经网络提取特征后，可以将特征图上的位置展开成一列表示；这些位置也常被称为视觉词元。

它不是原图中的一个完整对象，也通常不等同于一个原始像素。一个对象可能覆盖多个特征位置，一个位置的特征也可能包含周围区域的信息。

### 27 多尺度特征 Multi Scale Features

来自不同空间分辨率的图像特征。较细分辨率保留更多位置细节，较粗分辨率通常具有更广的上下文信息。

不同大小的对象可从不同尺度获得帮助。多尺度特征不一定意味着每次都把原图缩放成很多张独立输入图像。

### 28 骨干网络 Backbone

主要负责提取基础特征的网络。本文的图像骨干是Swin，文本骨干是BERT。

骨干只是整体模型的一部分。骨干输出后，还需要特征增强、查询选择和解码等处理，才能得到最终检测结果。

### 29 编码器与解码器 Encoder and Decoder

编码器把输入组织成适合后续处理的表示；解码器根据这些表示和查询生成任务输出。

“解码器”是功能名称，不一定输出文字。Grounding DINO的检测解码器更新对象表示，并用于预测框和短语得分。

### 30 注意力 Attention

一种根据相关性给信息分配不同权重、再进行汇总的计算机制。直观上，是让模型针对当前需要，从许多信息中读取较相关的部分。

它是数值计算过程，不等同于人类的注意力或理解，也不能仅凭注意力图证明因果机制。

### 31 查询 键 值 Q K V

注意力中的三个角色：**Query，查询Q**表示当前想读取什么；**Key，键K**用于计算与查询的相关性；**Value，值V**提供被加权汇总的信息。

可以类比检索：Q是检索需求，K用于匹配，V是取回的内容。模型实际使用的是向量和矩阵，而非文字数据库。

### 32 自注意力 Self Attention

Q、K、V来自同一组表示，使组内元素互相读取信息。

文本自注意力让词元利用其他词元的信息；对象查询自注意力则让不同候选对象表示交互。名称中的“自”指信息来源，不指某个词只看自己。

### 33 交叉注意力 Cross Attention

Q来自一组表示，K、V来自另一组表示，使一方读取另一方的信息。

例如对象查询作为Q，文本特征作为K、V，就是候选对象从文本中读取相关信息。**注意力的Q与“对象查询”有关联，但不是所有Q都代表检测对象候选。**

### 34 双向图文交互 Bidirectional Fusion

视觉读取文本，文本也读取视觉。判断某一层的信息流时，应看它的Q与K、V来自哪里，避免只凭模块的英文名称猜方向。

双向交互与BERT的“双向上下文”不是同一概念：前者发生在图像与文本之间，后者描述文本内部上下文的使用方式。

### 35 可变形注意力 Deformable Attention

通过学习采样位置及权重，从少量相关位置读取视觉信息，减少对所有图像位置逐一进行密集交互的负担。

这里的“可变形”是采样位置可以调整，不是把原始图像物体拉伸变形。它也不同于Swin的窗口移动机制。

### 36 前馈网络 FFN

全称为**Feed Forward Network**，通常由线性变换与非线性激活组成，用于进一步变换特征。

注意力主要负责信息之间的交互，FFN对得到的表示进行加工。它是Transformer层中的常见组件。

### 37 特征增强器 Feature Enhancer

本文位于基础编码与候选选择之间的融合模块，通过视觉/文本自注意力及双向交叉注意力更新两种模态的特征。

“增强”不表示把图像做亮度、颜色等数据增强，而是让模型内部表示更适合当前图文条件下的检测任务。

## 五 查询选择与文本组织

### 38 对象查询 Object Query

一个用于检索和表示潜在对象的候选单元。它从图像与文本特征中获取信息，随后用于预测框和文本匹配得分。

它不是用户输入的一句自然语言问题，也不是一个类别名称。多个查询可以关注同一类别的不同实例，候选中也可能有未对应真实目标的部分。

### 39 内容查询与位置查询 Content and Positional Query

内容部分携带候选对象的表示；位置部分描述候选从哪里、以什么空间范围获取信息。

本文的混合初始化中，内容查询可学习，位置部分由编码器输出的动态锚框初始化。不要把两部分都说成直接复制筛选出的图像特征。

### 40 锚框与动态锚框 Anchor Box

锚框是用框形式表达的空间参考。动态锚框会在模型处理过程中随预测更新，不是永久固定在同一位置的矩形。

在本文中，它承担位置查询的表示作用。参考框不等于最终正确框，仍需后续细化。

### 41 混合查询初始化 Mixed Query Initialization

将查询的不同组成部分用不同来源初始化。本文中，位置由编码器输出初始化，内容保持为可学习查询。

“混合”描述初始化方式，不表示把多个数据集随机混合，也不等于集成多个检测器。

### 42 语言引导查询选择 Language Guided Query Selection

用文本与视觉位置的匹配分数决定哪些位置进入有限的查询候选集合。

这里可以概括为三步：算图文点积 → 每个视觉位置取最高词元分数 → 选择分数最高的900个位置。文字改变时，候选位置可以随之改变。

### 43 点积与匹配分数 Dot Product and Matching Score

两个等长向量对应分量相乘后求和，即点积。本文利用点积产生视觉位置或对象查询与文本词元之间的匹配得分。

它表示模型学习到的匹配程度。没有额外校准时，高分不能直接解释为具有严格概率含义的“百分之多少肯定正确”。

### 44 转置 Transpose

将矩阵的行和列互换，常写作上标$\mathsf T$或$\top$。

文本特征$X_T$为$N_T\times d$，转置后为$d\times N_T$，从而可以与$N_I\times d$的图像特征相乘。这里$X_T$下标T表示文本，上标$\mathsf T$表示转置，是两个不同用途的符号。

### 45 Top K与索引 Top K Indices

Top-K是选出最大或最优的K项。**索引**是这些项在原数组中的位置编号。

本文选出的是900个视觉位置索引，不是900个类别，也不保证最终有900个有效对象。不是按每个类别分别选900个。

### 46 提示词与类别列表 Prompt

向模型提供的文本条件，可以是一串类别名称，也可以是一条描述。

例如`dog . cat .`是类别列表，`the dog on the left`是指代表达。提示中的分隔方式、类别顺序及长度可能影响处理，因此实验应固定并记录。

### 47 子句级文本表示 Sub Sentence Representation

本文指将文本组织成彼此相对独立的类别或短语片段，保留每个词元的表示，同时限制无关片段之间的交互。

这里的“子句”不要求是语法学上的完整从句；独立类别名也可以作为片段。它不会把整个类别列表都压成一个向量。

### 48 注意力掩码 Attention Mask

规定哪些位置之间允许发生注意力交互，哪些应被屏蔽的计算规则。

在本文中，它用于隔离无关类别片段。**注意力掩码与分割掩码不同：前者约束信息交互，后者标记图像像素。**

### 49 细化 Refinement

让候选对象表示和预测框经过多层处理逐步更新，使定位和语义匹配更准确。

它不是将原图放大、增加像素，也不意味着每层更新都必然提高每个框的质量。

## 六 训练方法与损失函数

### 50 预训练 微调与推理

- **预训练 Pre-training：**先在较大或较通用的数据上学习参数。
- **微调 Fine-tuning：**从已有参数出发，在目标任务或数据上继续训练。
- **推理 Inference：**使用已经训练好的参数对新输入给出预测，通常不更新参数。

例如先用O365和GoldG训练，再用COCO训练，是预训练后微调；直接输入一张新图获得框，是推理。三者不能混为同一种实验协议。

### 51 从头训练 Training from Scratch

强调目标模型没有直接从某个已训练好的完整目标模型继续训练。需要进一步核实作者具体初始化了哪些模块。

在检测论文中，“从头训练检测器”并不必然意味着图像、文本骨干都完全随机初始化。本文把从已有DINO迁移与从头训练Grounding DINO作比较时，不能自行扩大为“任何预训练权重都没有使用”。

### 52 零样本与直接迁移 Zero Shot Transfer

本文中，模型不使用目标数据集的训练划分，而是训练后直接在该数据集上评测。

“零样本”不等于整个模型没训练；“没有用COCO训练”也不等于没有通过O365见过与COCO相同的语义类别。更严格的未见类别协议需要额外检查类别重叠。

### 53 少样本与全样本 Few Shot and Full Shot

少样本表示使用有限的目标任务标注进行适配；全样本表示使用该协议允许的完整目标训练集。

它们都与完全不使用目标训练划分的直接迁移不同。论文中的ODinW少样本和全样本结果，不能并入零样本排名。

### 54 迁移 泛化与领域偏移

- **迁移 Transfer：**将一个训练来源获得的能力应用到另一任务或数据。
- **泛化 Generalization：**在未用于拟合的样本或条件下仍然表现良好。
- **领域偏移 Domain Shift：**训练和应用中的图像风格、场景、类别等分布发生变化。

从常见生活照片转到植物病害图像，就可能同时面临视觉和语义分布变化。跨域表现不能只靠一个数据集的高分代表。

### 55 参数 权重与检查点 Parameters Weights and Checkpoint

参数是训练中需要学习的数值；权重常作为参数的通俗称呼。检查点是某一训练时刻保存的模型状态文件，也可能包含优化器状态等信息。

“使用同一个检查点”意味着比较时固定训练得到的状态。模型结构相同但训练数据不同的权重，不能视作同一个实验对象。

### 56 冻结参数 Freezing

训练时让指定参数保持不变，仅更新其余部分。

冻结通常可以减少相应梯度与更新开销，但冻结模块仍可能需要前向计算。它不等于删掉模块，也不意味着整个模型没有训练。

### 57 标注 真值与监督 Annotation Ground Truth and Supervision

标注是数据附带的类别、框、文本对应关系等信息。真值GT是评测或训练时作为参考的答案；监督是利用这些参考信号指导学习。

真值也可能存在错误或歧义。“监督目标不同”表示任务要求不同，例如一条描述对应一个指定框，或对应多个对象。

### 58 伪标签与教师模型 Pseudo Label and Teacher Model

伪标签是模型自动产生、用作后续训练监督的标注；教师模型是提供这些监督的模型。

本文的Cap4M使用GLIP生成的伪框。它可以扩大训练数据覆盖，但会继承教师漏检、误检和类别偏差，不能直接等同于人工确认的真值。

### 59 区域与词元对齐 Region Token Alignment

训练模型让某个图像区域的表示，与描述它的文本词元具有较高匹配程度，并区分不对应的词元。

这样分类得分随输入文本变化，不必始终绑定固定类别编号。区域级对齐与“整张图是否匹配整句话”的学习粒度不同。

### 60 对比学习与对比损失 Contrastive Learning and Loss

一般思想是增加匹配表示之间的可区分对应关系，并压低不匹配组合的得分。具体采用的公式可能不同。

本文用查询与文本词元点积产生分类logits，再计算焦点损失。不要一听到“对比”就自动替换成CLIP式整图—整句、批内softmax损失。

### 61 分类头与logit Classification Head and Logit

分类头是产生类别得分的输出模块。logit是转成概率式分数之前的原始数值输出。

本文将对象查询与文本词元进行匹配，得分维度与输入文本相关。它不同于始终输出固定类别表分数的传统分类头。

### 62 匈牙利匹配 Hungarian Matching

一种求解一对一分配问题的算法。检测中先计算预测框与真实框两两对应的代价，再寻找整体总代价较小的匹配。

例如3个预测、2个真实目标，需要选出2组对应，不能让两个预测同时占用同一个真值位置。它不是简单地对每个预测独立选择最近框，也不是用于计算相似度本身。

### 63 匹配代价与训练损失 Matching Cost and Training Loss

匹配代价用于决定“哪个预测对应哪个真值”；训练损失用于衡量结果偏差并更新参数。

二者可以使用相似的分类和定位项，但权重不一定相同。本论文正文与表8的分类系数存在冲突，应分别记录，不能混成一个无争议的设置。

### 64 损失函数 Loss Function

将预测与训练目标之间的差异转成可优化的数值。训练通常希望降低总损失，但损失更低不保证每个测试指标都更好。

本文主损失的三类组成是分类、框坐标L1、GIoU，另外还有中间层辅助监督。它们分别约束语义对应与几何定位。

### 65 焦点损失 Focal Loss

一种调整分类样本贡献的损失，使大量容易分类的样本不会过度主导学习，让难例获得相对更多关注。

它并不是直接“把稀有类别权重调高”的同义词，因此使用焦点损失不代表已经解决长尾类别问题。

### 66 L1损失

对预测值和目标值的对应分量差取绝对值，再按设定规则求和或平均。本文用于约束预测框坐标。

简单例子：预测坐标0.4、目标0.5，这一分量的绝对误差是0.1。完整框损失还需考虑多个坐标以及实际归一化方式。

### 67 GIoU与GIoU损失

GIoU全称为**Generalized Intersection over Union，广义交并比**。它在IoU基础上引入包含两个框的最小外接框信息，能在两个框不相交时继续反映几何差异。

GIoU是相似性指标，常用的损失形式是$1-\mathrm{GIoU}$；二者优化方向不同。GIoU可为负值，不能把它当作始终介于0与1的普通IoU。

### 68 辅助监督 Auxiliary Supervision

不仅在最终输出上计算损失，也对中间层输出提供训练信号。

本文对编码器输出和各解码层使用辅助损失，帮助中间表示学习。它不意味着推理时必须额外输入人工答案。

### 69 AdamW与学习率 Learning Rate

AdamW是更新模型参数的优化算法，将权重衰减与自适应梯度更新解耦。学习率控制每次更新的步幅尺度。

本文主学习率为$10^{-4}=0.0001$，骨干学习率为$10^{-5}=0.00001$。较小的骨干学习率通常使已有表示更新得更谨慎，但不能简单认定学习率越小越好。

### 70 批大小 Batch Size与训练轮次 Epoch

批大小是一次参数更新所使用的一批样本数量。分布式训练中的全局批大小汇总各设备参与该次更新的样本；存在梯度累积时还要区分单次前向批大小与有效批大小。

Epoch通常指按训练协议遍历训练数据的一轮。它不同于一次参数更新；多数据源混合训练还需核对作者如何定义一轮。

## 七 指标与结果解读

### 71 TP FP FN与误检 漏检

| 缩写 | 英文 | 检测中如何理解 |
|---|---|---|
| TP | True Positive | 预测按评测规则正确匹配到一个真实目标 |
| FP | False Positive | 预测未正确匹配，可能是背景误检、类别错、位置不合格或重复框 |
| FN | False Negative | 真实目标没有被有效预测匹配到，即漏检 |

具体匹配还受类别、IoU、忽略标注等评测规则影响。一个定位很差的框，可能造成预测计FP、原目标仍计FN。

### 72 精确率 Precision

回答“模型报出的结果中，有多少是对的”：

$$
\mathrm{Precision}=\frac{TP}{TP+FP}.
$$

精确率高意味着误报较少，但不保证找全目标。只报告最有把握的一个目标，可能精确率很高而召回很低。

### 73 召回率 Recall

回答“所有真实目标中，有多少被找到了”：

$$
\mathrm{Recall}=\frac{TP}{TP+FN}.
$$

教学例子：有10个真实目标，模型报出8个框，其中6个正确、2个错误，则精确率为$6/8=75\%$，召回率为$6/10=60\%$。这两个数是在某个设定下得到的，并不是AP。

### 74 IoU 交并比

全称为**Intersection over Union**，用于衡量两个框的重合程度：

$$
\mathrm{IoU}=\frac{\text{交集面积}}{\text{并集面积}}.
$$

完全重合时为1，不相交时为0。若交集面积为6、并集为10，则IoU为0.6。注意分母不是两个框面积直接相加，因为重叠部分不能重复计算。

### 75 AP 平均精度

全称为**Average Precision**。直观上，将预测按分数排序，综合不同召回水平下的精确率；实际计算遵循基准的匹配和插值规则。

COCO常用主AP还在多个类别及IoU阈值上汇总；其默认IoU阈值是0.50、0.55，依次到0.95。具体实现见[COCO官方评测代码](https://github.com/cocodataset/cocoapi/blob/master/PythonAPI/pycocotools/cocoeval.py)。

**52.5 AP不等于52.5%的图片正确，也不是某个框的置信度。**“提高0.5 AP”是指标增加0.5点；从46.2到46.7并不是相对提高50%。

### 76 mAP与AP50 AP75

- **mAP，mean Average Precision：**通常指对类别等维度的AP求平均，具体定义仍以基准为准。
- **AP50：**使用IoU阈值0.50时的AP。
- **AP75：**使用IoU阈值0.75时的AP，对定位重合要求更高。

很多论文把已经跨类别平均的COCO主指标直接写成AP。不要仅因多了字母m，就把两个指标判为完全不同的性能口径。

### 77 APr APc APf

LVIS按类别在训练集中的出现频率，将类别划为**rare，稀有；common，常见；frequent，高频**，并分别汇总AP。

它们不是按目标大小分组，也不是按模型分数高低分组。总AP提高时，稀有类别APr仍可能下降；本文正出现了这种情况。

### 78 平均AP与中位AP

ODinW将多个数据集上的AP再汇总。平均AP是把各数据集AP相加后除以数量；中位AP是排序后位于中间的值。

教学例子：五个数据集AP为0、0、10、20、70，平均是20，中位数是10。少数高分会抬高平均数；中位数更高也不能单独证明方差一定更小。

### 79 Top 1定位准确率

Top-1表示只检查模型排序第一的预测。REC中，判断这个首选框是否按基准规则成功定位到所指对象，再对全部表达统计成功比例。

候选里存在正确框但它没有排第一，仍可能判失败。它不同于图像分类准确率，也不同于检测AP；成功定位的IoU等条件应查对应基准协议。

### 80 置信得分与阈值 Confidence Score and Threshold

置信得分是模型给预测的评分；阈值是决定保留哪些结果的边界。通常提高筛选阈值会减少保留框，同时可能减少误检并增加漏检。

不同类别和领域的得分未必处于同一可靠尺度，0.8不能未经校准就解释为80%的真实正确概率。模型分数、框匹配用的IoU阈值、注意力权重，是不同概念。

### 81 拒识与分数校准 Rejection and Calibration

拒识指模型在目标不存在或证据不足时不强行给出肯定结果。校准关注模型得分与实际正确性的对应关系是否可靠。

简单调高阈值可能减少误报，却也可能大量漏检，因此要在相同召回等条件下比较。能输入不存在的类别名称，不代表模型一定能可靠拒识。

### 82 参数量 计算量与速度

| 名词 | 含义 | 本文数字如何读 |
|---|---|---|
| 参数量 Params | 模型中参数的数量 | 172M约为1.72亿个参数 |
| FLOPs | 一次指定计算过程的浮点运算量 | 表中464G表示约4640亿次量级，取决于计数规则 |
| GFLOPs | 以十亿次为单位的浮点运算量 | 论文表头有时简写GFLOPS，需结合上下文判定 |
| FPS | Frames Per Second，每秒处理帧数 | 8.37 FPS是特定测速环境下的吞吐表现 |
| GPU | 用于并行计算的处理器 | V100和A100是不同GPU型号 |

参数量不是图像数量；计算量不是实际秒数。相同FLOPs可能因硬件、输入尺寸和实现方式而具有不同FPS。严格说FLOP/s还可表示每秒运算速率，阅读表头时应区分“运算量”和“速率”。

## 八 实验设计与可信度

### 83 基线 Baseline

作为比较起点的方法或设置，例如DINO、GLIP，或完整模型的一个简化版本。

好的比较要尽量匹配骨干、数据、训练资源和评测协议。仅模型名称相似，不足以证明条件一致。

### 84 消融实验 Ablation Study

改变或移除一个组件，观察指标变化，帮助判断该设计在系统中的作用。

本文分别移除编码器融合、改用静态查询、移除文本注意力等。它支持组件在当前系统中的价值，但组件之间可能存在交互，差值不能直接相加。

### 85 对照与控制变量 Controlled Comparison

对照是用来比较的另一条件；控制变量是尽量让无关因素保持一致，从而更清楚地判断某项改动的影响。

如果同时改骨干、数据量和训练时长，即使AP提高，也无法只归因于某个新增模块。这就是汇报中“收益归因”需要谨慎的原因。

### 86 数据划分与验证集 Validation Set

训练集用于学习参数，验证集用于模型选择、调参或阶段性评估，测试集用于按既定协议最终评价。表格中的`val`通常表示验证集。

`test-dev`是COCO的一种测试评测入口名称，不等同于val。不同划分、图像尺寸或微调状态的结果不能不加说明地混比。

### 87 数据泄漏 Data Leakage

本应作为独立评测的信息，通过训练数据、重复图像、教师模型或调参过程等途径进入模型选择或学习。

例如训练与评测包含同一图像，即使标注任务不同，也应评估重叠对结论的影响。泄漏风险不等于已经证明全部结果无效，但必须披露并检查。

### 88 随机种子 重复运行与不确定性

随机种子控制初始化、数据打乱等随机过程。相同设置多次运行可能产生不同指标。

重复运行及波动区间有助于判断小幅提升是否稳定。单次提高0.3 AP，不能自动当作已经证明具有稳定优势或统计显著性。

### 89 长尾分布 Long Tail Distribution

少数类别样本很多、大量类别样本很少的数据分布。稀有类可学习的视觉变化有限，因此通常更难训练和评估。

长尾与“完全没有见过该类别”不同：稀有类别可以在训练中出现，只是出现次数少。专业领域失败也不一定只由长尾造成，还可能涉及风格、标注和任务差异。

### 90 训练配方与算力预算 Training Recipe and Compute Budget

训练配方包括所用数据、采样比例、骨干、初始化、优化器、训练轮次等设置；算力预算描述设备、训练时间或总计算资源。

“用了同样数据集名称”不保证图像版本、采样次数和训练预算相同。比较架构时，需要尽量同时检查这些条件。

### 93 如何读一行数据配方

例如：

`Grounding DINO T + O365 + GoldG + Cap4M`

表示使用T模型，训练数据包含这些来源。加号主要列出组合关系，不交代具体采样比例，也不表示按相同轮次依次训练。

判断“零样本”还要问：**相对于哪个目标数据集？目标训练划分是否使用？是否存在图像或教师知识重叠？**同一权重可以对某数据集是迁移，对另一数据集则已见过训练数据。

## 十 公式符号与表格后缀

### 94 查询选择公式的每个符号

$$
X_I\in\mathbb R^{N_I\times d},\quad
X_T\in\mathbb R^{N_T\times d},\quad
S=X_I X_T^{\mathsf T},\quad
s_i=\max_j S_{ij}.
$$

| 符号 | 含义 | 不要混淆 |
|---|---|---|
| $X_I$ | 图像特征矩阵 | 下标I表示image |
| $X_T$ | 文本特征矩阵 | 下标T表示text |
| $N_I$ | 图像特征位置数量 | 不是对象数量 |
| $N_T$ | 文本词元数量 | 不是类别数或单词数 |
| $d$ | 每个向量的维度，本文为256 | 不是类别数量 |
| $S$ | 图像位置与文本词元的匹配矩阵 | 形状为$N_I\times N_T$ |
| $S_{ij}$ | 第$i$个位置与第$j$个词元的分数 | i与j是两个不同维度的索引 |
| $s_i$ | 第$i$个视觉位置的最高词元分数 | 对文本维取最大值后的结果 |
| $\max_j$ | 在所有文本词元索引j上取最大值 | 不是把所有词元分数相加 |
| $\operatorname{TopKIndices}$ | 返回分数最高的K个位置索引 | 不是返回K个类别 |
| $N_q$ | 对象查询数量，默认900 | 不等于最终有效输出数量 |
| $\mathbb R$ | 实数集合 | 表示矩阵元素为实数 |

### 95 损失公式的每个符号

$$
\mathcal L=
\mathcal L_{\mathrm{cls}}+
5\mathcal L_{\mathrm{L1}}+
2\mathcal L_{\mathrm{GIoU}}.
$$

| 符号 | 这里的意思 |
|---|---|
| $\mathcal L$ | 总损失的概括表示 |
| cls | classification，分类项，约束对象与文本的对应 |
| L1 | 框坐标的绝对误差项 |
| GIoU | 框的几何重合相关损失项 |
| 5与2 | 损失权重，调节各项对总目标的贡献 |

这些权重不意味着“分类准确率加5倍定位准确率”。**损失是训练目标，AP是评测指标。**上式来自正文权重概括，并未展开所有辅助层的损失。

## 十一 最容易混淆的十二组概念

| 容易混淆的一组 | 正确区分 |
|---|---|
| 开放词汇能力 / 无所不知 | 接口可接收新词，不保证已学会所有视觉概念 |
| 零样本 / 没训练过 | 本文只是未用目标训练划分，模型已进行大量预训练 |
| 类别 / 实例 | 类别是种类，实例是某个具体对象 |
| 对象查询 / 用户问题 | 前者是模型候选表示，后者是文本输入 |
| 900查询 / 900有效目标 | 候选预算不等于最终目标数量 |
| 词元 / 单词 / 类别 | 三者没有固定一一对应关系 |
| 256维 / 256类别 | 前者是向量宽度，后者才是标签集合大小 |
| 注意力掩码 / 分割掩码 | 前者限制交互，后者标记像素 |
| 匹配代价 / 训练损失 | 前者决定对应关系，后者用于参数优化 |
| AP / 置信度 / 准确率 | 前者汇总检测排序性能，中者是单条预测评分，后者是按规则判对比例 |
| 总AP / 稀有类AP | 汇总提升可以与稀有类退化同时发生 |
| 参数量 / 运算量 / 运行速度 | 数值规模、计算工作量与实际吞吐是不同维度 |

## 十二 用一段话串起整篇论文

Grounding DINO接收图像和文本提示。Swin骨干将图像变成多尺度特征，BERT将文本变成词元特征。特征增强器利用自注意力和交叉注意力进行图文融合；语言引导查询选择根据匹配分数筛选900个视觉位置，初始化候选的位置部分；解码器继续读取图像和文本并细化候选，最后预测边界框与短语得分。训练时通过匈牙利匹配建立预测与真值的对应，并计算分类及定位损失。评测时用COCO、LVIS和ODinW的检测AP检查迁移能力，用RefCOCO系列的首选框定位准确率检查指代理解。

**能够不看稿讲清这段话，再解释“本文零样本的口径”和“总AP不代表所有类别都好”，就具备了第一次组会讲解这篇论文的核心术语基础。**
