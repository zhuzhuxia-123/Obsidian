按你前面那条路线，建议先看 **目标检测基础 → DETR**，再分成 **CLIP → Grounding DINO** 和 **KITTI 投影 → PointPillars → BEVFusion** 两支。每支看完就做一个小实验，方便你判断哪条更适合做小论文。

### 共同基础

|B 站视频|重点看什么|
|---|---|
|《动手学深度学习 v2》目标检测相关分集|选看「物体检测」「锚框」「目标检测」「SSD」。先弄懂边界框、IoU、正负样本和 NMS。会跑检测模型的话，可以直接跳到 DETR。 [B 站合集，P122–P133 选看](https://www.bilibili.com/video/BV1ihoVYEEp3/?p=122)|
|李沐《DETR 论文精读》|看懂 object query、匈牙利匹配，以及模型怎样同时输出类别和框。后面读 Grounding DINO 时会直接用到。 [B 站原视频](https://www.bilibili.com/video/BV1GB4y1X72R/)|

### 2D 开放词汇检测

1. **李沐《CLIP 论文逐段精读》**。重点看图像与文本如何做对比学习，以及类别名称怎样变成可比较的文本特征。看完可以裁一张目标图，比较同义词和相似类别的得分。 [B 站原视频](https://www.bilibili.com/video/BV1SL4y1s7LQ/)
2. **《Transformer DINO 和 Grounding DINO 讲解》**。前面是复习，已经看过 DETR 可以从约 **20 分钟**开始。重点看文本在哪里进入检测流程。看完固定同一批图片，分别加入同数量的随机类别和相似类别，记录框消失和类别判错各有多少。 [B 站视频](https://www.bilibili.com/video/BV1kY8zeUEAX/?t=1200)

### 相机 + LiDAR 多模态 3D 检测

1. **《Open3D 系列（2）—将点云投影到图像上》**。跟着用 KITTI 的内外参，把一帧 LiDAR 点云叠到对应图像上。这是后续做融合和外参扰动实验的基础。 [B 站视频](https://www.bilibili.com/video/BV1oM4y1s7YH/)
2. **OpenMMLab《MMDetection3D 系列课程》**。优先看第 2 集「预训练模型推理」、第 3 集「KITTI 数据集和坐标系」、第 5 集「PointPillars 配置」。这是较早的课程，安装和运行命令以你选用版本的文档为准。PointPillars 可以作为后续融合实验的 LiDAR 单模态对照。 [B 站课程合集](https://www.bilibili.com/video/BV1Xe4y1g7Xv/) · [官方推理文档](https://mmdetection3d.readthedocs.io/en/latest/user_guides/inference.html)
3. **自动驾驶之心《大火的 BEVFusion 算法详解》**。看相机和点云特征怎样进入同一个 BEV 空间，以及在哪里融合。先用它建立架构概念，实操从上面的 KITTI 和 PointPillars 开始。 [B 站视频](https://www.bilibili.com/video/BV1ix4y1f7mX/)

**这周可以先看 DETR，再各做一个小练习**：2D 用 Grounding DINO 改一次词表，3D 用 KITTI 投影一帧点云。两边都有实际输出后，再往验证集评测推进。
