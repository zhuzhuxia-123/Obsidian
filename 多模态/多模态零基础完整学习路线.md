# 多模态零基础完整学习路线

适用对象：研一人工智能专硕学生，Python 和人工智能均从零开始。

建议周期：约 **9～12 个月，每周 12～15 小时**。时间是规划参考，以完成每阶段的小项目为准。

路线以计算机视觉多模态为主：

**Python → 必要数学与机器学习 → PyTorch 与图像分类 → Transformer → CLIP 图文对齐 → 多模态大模型 → 论文复现与选题**

“多模态”就是让模型同时处理不同形式的信息，例如图片和文字。第一个多模态项目可以很简单：输入“海边的狗”，从一批照片里找出最匹配的图片。

顶会论文可以先收藏，等能独立训练一个小模型、运行一个图文模型，再读会更有效。

## 二、第1阶段：Python 与学习工具——第1～4周

目标：能自己写一个小程序，并看懂报错。

重点学：

- 变量、字符串、列表、字典。
- 判断、循环、函数。
- 文件读写、异常处理。
- 类与对象的基本用法。
- 安装软件包，使用编辑器或 Jupyter Notebook。

主视频选 **UP主「黑马程序员」的 [Python入门课程](https://www.bilibili.com/video/BV1qW4y1a7fU/)**。只学 Python 基础、文件操作和简单面向对象部分；后面的数据库、大数据内容暂时跳过。

配套书是《Python编程：从入门到实践》的基础部分。

**小项目：图片目录统计器。** 输入一个文件夹，统计里面有多少张图片，按扩展名分类，把结果写进 CSV 文件。之后加上读取图片宽高的功能。

**过关标准：能解释自己写的每个函数，修改需求后能自行调整程序，而不只是照抄视频。

如果已经会这些内容，可以直接进入第2阶段。

## 三、第2阶段：必要数学与机器学习概念——第5～8周

目标：理解“模型怎样从数据中学习”，能看懂简单公式。

数学只先补这些：

| 内容 | 后面用在哪里 |
|---|---|
| 向量、矩阵、矩阵乘法 | 表示图片、文字和模型参数 |
| 点积、余弦相似度 | 比较图片与文字是否匹配 |
| 导数、偏导、链式法则 | 理解模型如何更新参数 |
| 概率、期望、条件概率 | 理解预测与不确定性 |
| 梯度下降 | 理解训练过程 |

数学视频选 **「3Blue1Brown」的 [《线性代数的本质》](https://www.bilibili.com/video/av5987715/)**，先看向量、线性变换、矩阵乘法、点积，建立直觉。它适合辅助理解，练习仍要自己做。

机器学习部分，从[《动手学深度学习》](https://zh.d2l.ai/)的预备知识、线性回归和分类基础开始。重点弄明白：

- 训练集、验证集、测试集分别有什么作用。
- 参数、损失函数、学习率是什么。
- 什么叫过拟合，为什么要验证模型。
- 分类准确率如何计算。

**小项目：拟合一条直线。** 自己生成带噪声的数据，学习斜率和截距，画出拟合结果。改变学习率，观察损失为什么有时下降、有时震荡。

**过关标准：**能用自己的话说明“预测 → 计算误差 → 更新参数”的过程。

## 四、第3阶段：PyTorch 与图像分类——第9～16周

PyTorch 是帮助搭建、训练模型的工具。这个阶段是后面多模态学习的基础。

先看 **UP主「我是土堆」的 [PyTorch快速入门教程](https://www.bilibili.com/video/BV1hE411t7RN/)**，熟悉数据加载、模型定义和训练代码。[作者代码仓库](https://github.com/xiaotudui/pytorch-tutorial)也公开可用。

随后以 **「跟李沐学AI」的 [《动手学深度学习》官方课程目录](https://courses.d2l.ai/zh-v2/)为主线。目录提供各节视频入口，课程包含原理与 PyTorch 实现。

重点学：

- 张量：可以理解为模型使用的多维数组。
- 自动求导、损失函数、优化器。
- 数据集与批量加载。
- 多层感知机、卷积神经网络。
- ResNet、迁移学习。
- 模型保存、加载与验证。

**两个练习项目：**

1. 用简单网络完成 Fashion-MNIST 服饰分类。
2. 用预训练模型完成一个小型图片分类任务，例如猫狗分类。

第二个项目中要自己完成数据划分，保存训练曲线，检查预测错误的图片。

**过关标准：能独立写出完整训练与验证流程，解释训练准确率很高、验证准确率较低的原因。

两个课程的重复部分不必都看完：小土堆用于熟悉工具，李沐用于补足原理。

## 五、第4阶段：Transformer 与视觉、文字表示——第17～20周

这个阶段把图片和文字两条知识线连接起来。

需要理解：

- **Embedding：把信息转换成向量。
- **Token：模型处理信息的基本单位，例如文字片段或图像块**。
- **Attention：模型怎样利用不同位置的信息。
- 自注意力、多头注意力、位置编码。
- ViT 怎样把图像块输入 Transformer。
- 语言模型怎样预测下一个文字 token。

配套视频：

- **李宏毅《生成式人工智能导论》中的第10讲及 Transformer 延伸课。这里提供的是 UP主「啥都会一点的研究生」整理的[B站课程合集](https://www.bilibili.com/video/BV1BJ4m1e7g8/)，课件可在[教师官网](https://speech.ee.ntu.edu.tw/~hylee/genai/2024-spring.php)获取。
- **跟李沐学AI：[Transformer论文逐段精读](https://www.bilibili.com/video/BV1pu411o7BE/)**。
- **跟李沐学AI：[ViT论文逐段精读](https://www.bilibili.com/video/BV15P4y137jb/)**。

先看通俗课程，再看论文精读。第一次不必吃透所有推导。

**小项目：实现一个简化的注意力模块。** 给定几组向量，计算注意力权重并画出来；然后运行预训练 ViT 做图片分类。

**过关标准：能追踪张量形状，并解释文字 token 和图像 token 怎样进入模型。

## 六、第5阶段：第一个多模态模型——CLIP——第21～24周

CLIP 是很适合入门的多模态入口：它分别将图片和文字转换为向量，再学习哪些图文应该相互匹配。

学习内容：

- 图像编码器与文字编码器。
- 对比学习：匹配的图文靠近，不匹配的图文远离。
- 相似度矩阵与温度参数。
- 零样本分类：不针对新类别训练，也能通过类别文字描述进行识别。
- 图文检索与提示词设计。

配套视频按这个顺序：

1. **RethinkFun：[多模态模型CLIP深度讲解](https://www.bilibili.com/video/BV1pYmDYgEDW/)**，先建立结构理解。
2. **跟李沐学AI：[CLIP论文逐段精读](https://www.bilibili.com/video/BV1SL4y1s7LQ/)**，再理解研究问题和实验。

**小项目：文字搜图。**

准备一批照片，提前计算每张图的特征。输入“草地上的动物”等描述，返回最匹配的几张图。然后比较不同描述方式，整理模型找错的案例。

还可以增加“图片搜图片”功能。

**过关标准：**能解释相似度分数的含义，知道相似度分数不能直接当作“回答正确的概率”。

这个阶段先使用预训练模型，训练部分从小规模对比学习练习开始。

## 七、第6阶段：多模态大模型——第25～30周

现在再学习“看图聊天”的模型，结构会容易理解得多。

常见入门结构可以这样看：

**图片 → 视觉编码器 → 连接模块 → 语言模型 → 回答**

要学习：

- CLIP 与能生成回答的视觉语言模型有什么区别。
- BLIP-2 的 Q-Former 如何连接视觉与语言。
- LLaVA 怎样进行视觉指令微调。
- 预训练、监督微调、推理分别在做什么。
- LoRA 如何减少需要训练的参数。
- 图文数据如何组织、模型如何评测。

配套视频：

- **RethinkFun：[BLIP-2讲解](https://www.bilibili.com/video/BV1bVBRYTEpL/)**。
- **RethinkFun：[LLaVA系列讲解](https://www.bilibili.com/video/BV12PznYuExg/)**。
- 前面李宏毅课程中的第6、7、12讲，分别帮助理解训练过程与评测。

工程练习可参考免费的 [Hugging Face LLM课程](https://huggingface.co/learn/llm-course/chapter1/1)。它主要讲语言模型与工具生态，用于补基础，不能代替多模态学习。

**小项目：图片问答评测程序。** 批量输入图片和问题，保存模型回答，对比人工答案，统计错误类型，例如物体认错、数量数错、位置关系判断错。

先完成推理与评测；有实验室 GPU 后，再尝试小规模 LoRA 微调。

**过关标准：既能运行模型，也能说明它在哪些问题上失败，以及怎样公平地比较改进前后的表现。

## 八、第7阶段：论文复现与研究入门——第31～40周

第一个研究方向，建议选 **“图文冲突下的模型可靠性”**。

此时再读：

**[Words or Vision: Do Vision-Language Models Have Blind Faith in Text? — CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/papers/Deng_Words_or_Vision_Do_Vision-Language_Models_Have_Blind_Faith_in_CVPR_2025_paper.pdf)**，配合[作者代码](https://github.com/d-ailin/blind-faith-in-text)复现其中一个实验。

按下面的顺序开展：

1. 读懂任务、数据、评价指标和基线。
2. 先复现一个小规模实验，确认流程正确。
3. 阅读错误样例，提出一个可验证的问题。
4. 做对照实验，只改变一个主要因素。
5. 记录模型版本、配置、数据划分和结果。
6. 写一份短报告：问题、方法、结果、失败情况与限制。

例如：**同一张图片逐渐变模糊时，错误文字对模型回答的影响是否增大？** 这是一个实验问题，是否能发展成论文，需要进一步查阅已有工作并验证。

课程之外，还要逐渐学会 Git、Linux 常用命令、实验配置管理，以及阅读英文论文。这些可以随项目补充。

## 九、完成主线后，再选择一个分支

| 分支 | 需要增加的知识 | 建议起点 |
|---|---|---|
| 图文理解与可靠性 | 幻觉、图文冲突、细粒度识别 | 继续做图文问答评测 |
| 多模态效率 | token剪枝、量化、显存与延迟分析 | 先测量现有模型的运行成本 |
| 视频理解 | 抽帧、时间定位、跨帧记忆 | 从短视频问答开始 |
| 音频与视觉 | 声学特征、音画对齐、模态缺失 | 从声音与视频事件匹配开始 |
| 图像生成 | 扩散模型、条件控制、生成评测 | 补生成模型基础后再做 |

进阶时可参考 **[CMU多模态机器学习课程](https://cmu-multicomp-lab.github.io/mmml-course/fall2026/)**，系统了解表示、融合、对齐等问题。2026秋季版正在进行中，后续内容以课程实际发布为准。

## 十、现在只需要执行前四周

| 周次 | 主要任务 | 本周成果 |
|---|---|---|
| 第1周 | 安装Python与编辑器，学习变量、判断、循环 | 独立写出几个小程序 |
| 第2周 | 学列表、字典、函数 | 做一个成绩统计程序 |
| 第3周 | 学文件读写、路径、异常处理 | 读取文件并输出统计结果 |
| 第4周 | 完成图片目录统计器，补简单绘图 | 一个能重复运行的小项目 |

每天可以安排 **40分钟视频或阅读、60分钟编程、20分钟复盘**。遇到数学或代码不懂时，回到具体例子解决。

前期的小型练习可以用普通电脑和 CPU 完成；到多模态大模型推理、微调阶段，再根据模型大小使用实验室 GPU。

**近期最重要的目标，是一个月后能独立完成第一个 Python 小项目。**
